# Paxology public research hub

This repository publishes the public research program of Ildar “Dar” Fazulyanov.

**Canonical site:** https://paxology.ai/

## Public architecture

- **Paxology** is the overarching science/framework.
- **Systemic Value** is the organizational implementation method.

## Corpus

The five PDFs in `papers/` are byte-identical mirrors of the local July 6, 2026 SSRN submission corpus. `paper-register.json` records versions, page counts, byte sizes, and SHA-256 hashes.

## Boundaries

The site intentionally excludes private authorship evidence, patent-sensitive material, NDA-protected company evidence, and unpublished operating cases. Working papers are described as preliminary rather than peer-reviewed or settled.
